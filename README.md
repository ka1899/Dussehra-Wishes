# Happy Dussehra 🏹

A small Dussehra greeting site: Lord Rama's flaming arrow burns the Ravana effigy, with fireworks and wishes you can copy and share.

**Live site:** https://ka1899.github.io/dussehra-wishes/

## Features

- Personalised greeting: type a name, or share a link ending in `?name=Asha`
- "Light the effigy" button: the arrow flies and Ravana burns
- Click anywhere for fireworks
- Nine wishes with a Copy button
- Optional GIF: add a file named `ram.gif` next to `index.html` and it shows under the effigy

## Run locally

Open `index.html` in a browser. There is nothing to install.
