# Happy Dussehra 🏹

A small Dussehra greeting site: Lord Rama draws his bow and fires a flaming arrow at the ten-headed Ravana effigy, which catches fire and falls, with fireworks.

**Live site:** https://ka1899.github.io/dussehra-wishes/

## Features

- Click "Release Divine Arrow" or the scene itself to shoot; click again to rebuild and shoot again
- Animated SVG scene: Rama draws the bowstring, the arrow flies with a fire trail, Ravana burns
- Fireworks when the arrow hits
- Bow-and-arrow favicon

## Run locally

Open `index.html` in a browser. There is nothing to install.
